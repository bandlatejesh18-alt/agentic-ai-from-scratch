# Agentic AI From Scratch

Build an Agentic AI framework from scratch without relying on frameworks such as LangChain, LangGraph, CrewAI, or AutoGen.

This project demonstrates the core building blocks behind modern AI agents, including:

- Tool Calling
- Tool Registry
- Agent Loop
- Structured Outputs
- JSON Schema Validation
- Pydantic Validation
- Modular Architecture

> 🚧 This repository is currently under active development.
